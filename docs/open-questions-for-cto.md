# Open questions for the CTO

The skills follow the engineering guide. Where they add a rule the guide does not state, the skill
labels it `(team convention, not in the guide)`; where they read the guide one way among several,
they say so. Each row below needs a yes, a no or a correction. Until answered, agents use the safe
default (the more restrictive reading). Line numbers refer to the files at this commit.
