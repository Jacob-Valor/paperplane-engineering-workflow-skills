Commands, in order (`<skill>` = `~/.agents/skills/paperplane-shipping-changes`):

1. `git config --show-origin --get user.email` confirms the commits go out under Dara's identity, not someone else's.
2. `bash <skill>/hooks/install-git-hook.sh` installs the pre-push hook once per clone, so pushes to protected branches are blocked.
3. `git status --short`, then `git add <each changed file by name>` and `git commit -m "fix(auth): otp timeout no longer expires early"`. This stages only the intended files, never `-A` or `.`. I skip the commit if the work is already committed.
4. `bash <skill>/scripts/pre-push.sh` checks branch, identity, lockfiles, `.env`, build output and secrets before anything leaves the machine.
5. `git push -u origin fix/otp-timeout` pushes the branch.
6. Write the body below to `${TMPDIR:-/tmp}/pr-body.md`, outside the working tree.
7. `gh pr create --draft --base develop --title "fix(auth): otp timeout no longer expires early" --body-file "${TMPDIR:-/tmp}/pr-body.md"` opens the PR as a draft.
8. `git diff origin/develop...HEAD` shows the full diff, which I hand to Dara with the PR URL. Then I stop.

**What I do NOT do**
- **Mark it ready:** Dara hasn't reviewed the full diff, and Android is untested. It stays draft until Dara reviews the diff and says so.
- **Enable auto-merge (`gh pr merge --auto`):** that is a merge decided in advance, and only the author turns it on. I don't merge or approve either.
- **Bypass hooks or force-push:** I use no `--no-verify`, no force-push and no rebase.
